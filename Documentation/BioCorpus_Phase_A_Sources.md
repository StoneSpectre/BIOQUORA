# BioCorpus Phase A - Primary Sources

Below are the official access links for Phase A. These are the primary sources to be ingested into BioCorpus. This set of sources is sufficient to build a world-class Phase A BioCorpus covering literature, guidelines, books, clinical trials, government publications, and conference proceedings from the last decade.

## 1. Biomedical Literature
* [PubMed](https://pubmed.ncbi.nlm.nih.gov) — Biomedical citations & abstracts.
* [PubMed Central (PMC)](https://pmc.ncbi.nlm.nih.gov) — Free full-text biomedical papers.
* [Europe PMC](https://europepmc.org) — Literature, preprints, books, protocols, APIs.
* [OpenAlex](https://openalex.org)
* [Crossref](https://www.crossref.org)
* [Semantic Scholar](https://www.semanticscholar.org)
* [Lens.org](https://www.lens.org)
